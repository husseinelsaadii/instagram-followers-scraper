SETUP GUIDE

Find your access details

1

Copy the session and CSRF cookies

  1. Open instagram.com in Chrome or Edge and sign in.
  2. Open Developer Tools: right-click the page and choose Inspect. On Mac, you can press ⌘ + ⌥ + I; on Windows/Linux, press Ctrl + Shift + I.
  3. Select the Application tab. If it is hidden, click the » menu first.
  4. In the left sidebar, expand Storage → Cookies, then select https://www.instagram.com.
  5. In the cookie table, find sessionid. Click its row and copy the full text in the Value column. Paste it into “Session cookie.”
  6. Find csrftoken the same way and paste its value into “CSRF token.”
Keep these private. Anyone with your session cookie may be able to access your Instagram account. Never commit it to GitHub or send it to another person.
2

Find the target profile’s numeric ID

  1. Keep Developer Tools open and select the Network tab.
  2. Visit the target Instagram profile, then click its followers or following count.
  3. In the Network filter, type friendships. Choose the request containing /followers/ or /following/.
  4. Under Headers → Request URL, look for a path like:
    /api/v1/friendships/787132/followers/
  5. Copy only the number between friendships/ and /followers (or /following). That is the numeric profile ID.

Nothing appeared? Clear the Network list, make sure recording is on, close the followers window, and open it again.
